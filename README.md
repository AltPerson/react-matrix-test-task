# React Matrix Test Task

Frontend test task built with React, TypeScript and React Context.

## Features

- Generate M x N matrix
- Random three-digit values
- Row sum calculation
- 60th percentile calculation for each column
- Increment cell value on click
- Highlight X nearest cells on hover
- Show row percentages on sum hover
- Row heatmap
- Add and remove rows

## Tech Stack

- React
- TypeScript
- React Context
- CSS

## Run locally

```bash
npm install
npm run dev
```
